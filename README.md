# Career Portfolio

A simple portfolio website built with HTML, CSS, and JavaScript and hosted with GitHub Pages.

## Project structure

```text
.
|-- index.html       # Page content and structure
|-- css/
|   `-- styles.css   # Colours, typography, layout, and responsive styles
|-- js/
|   `-- main.js      # Small interactive enhancements
`-- assets/
    `-- images/      # Project images, headshot, and other graphics
```

## Work on the site locally

1. Open this folder in Visual Studio Code.
2. Open `index.html` in a browser, or use the VS Code **Live Server** extension.
3. Replace the placeholder text in `index.html` with your own story and projects.
4. Change the design tokens near the top of `css/styles.css` to explore the visual style.
5. Commit small, meaningful changes as you learn.

## Useful Git commands

```powershell
git status
git add -- index.html css/styles.css js/main.js
git commit -m "Describe what changed"
git push
```
